# Hands-On Lab: Using AlienVault OTX to Identify Cybersecurity Threats

---

## Answer Key and Explanation for Instructor:

### Task 1: Register and Explore the OTX Platform
- **Main Components:** Pulses, Dashboard, Subscriptions, API access, and User contributions.
- **Advantage:** Centralized source of community-driven threat intelligence with real-time IOCs.

### Task 2: Search for a Known Threat Actor or Malware
- **Example Search:** Cobalt Strike
- **Three IOC Types:** IP addresses, file hashes (MD5/SHA256), domains/URLs.
- **Pulse Source:** Typically from a security vendor like AlienVault or community contributors.

### Task 3: Create a Custom IOC Pulse
- **Pulse Name:** (Student-generated; sample: “Suspicious Comms to 203.0.113.50”)
- **Threat Type:** Suspicious communication potentially linked to malware C2.
- **Importance of Sharing:** Enhances collective defense by informing others of emerging threats and attack infrastructure.

---

## Key Takeaways:
- AlienVault OTX is a free platform for discovering and sharing cyber threat intelligence.
- Creating and contributing pulses helps organizations stay informed and proactive.
- Identifying and sharing IOCs supports the cybersecurity community’s ability to detect and mitigate threats.
